# dsh-xhs-style

在选品、版本选择和竞品分析前，先通过多轮反问验证真实痛点、硬约束与原始方案，确认路线后再调研；正式回复按「小红书爆款文案」的骨架组织：结论先行、星级对比表开场、emoji 分点、门槛分组、每条写到数值和步骤这一级；讲实物和推荐时强制图文并茂，图必须逐张核验内容、一图带一条来源链接；同时屏蔽一批营销烂词。

## 它解决什么问题

默认的 agent 回复容易写成「两行式空泛要点」：有结论没数据，有建议没步骤，有推荐没来源。这个插件把「排版密度」和「内容可核验性」写进系统提示，作为硬性输出契约：

- **需求契约**：选品与竞品任务先澄清真实目标、硬约束、必须项和替代路线；未经确认，不直接生成候选清单、正式报告或发帖文案。
- **结构契约**：钩子一句话 → 星级对比表 → 「最推荐先试」→ 按门槛分组 → 注意事项 → 怎么选。
- **密度契约**：每个条目 4–6 条实操 bullet，必须落到型号、尺寸、价格、步骤、材料用量，不允许只写方向。
- **溯源契约**：涉及实物、案例、推荐时配图，图注明来源链接与作者；图必须来自目标内容的正文媒体区，落盘后逐张核验，不合格就回源换一篇，不允许拿错图凑数。
- **用词契约**：禁用集美、闭眼冲、绝绝子、yyds 一类称呼与营销话术。

## 它不做什么

- 不改代码块、命令、路径、报错信息的格式（原样保留，不加 emoji）。
- 不套用到对外汇报、文档、邮件等正式产出。
- 用户说「正常格式」「严肃回答」「别用小红书格式」时立即退回普通排版。
- 普通资料查询、事实问答、纯资料搜集和既有文案改写不触发需求澄清。
- 用户说「别问了」「直接给」「按我说的买」时停止反问，列出假设与风险后直接执行。
- 不联网、不采集、不上报。插件只注入系统提示文本，不自行执行调研。

## 选品与竞品分析的工作流

1. **验证真实痛点**：确认场景、频次、现有解决方式，以及用户点名功能究竟解决什么问题。
2. **核对硬约束**：确认预算、安装、空间、兼容、维护条件和不可接受的后果。
3. **重新评估路线**：比较原方案、替代方案、最低成本方案，必要时建议暂不购买。
4. **同步需求确认卡**：列明真实目标、硬约束、必须项、可选项、已排除路线和待确认假设。
5. **确认后再产出**：先交代原始诉求与确认需求的差异，再联网调研、生成报告和小红书文案。

默认澄清 2–3 轮，每轮只问 2–4 个会改变选择的问题；下一轮根据回答继续追问，不重复已知信息。澄清轮不强制配图、星级表和长报告，避免用排版掩盖需求尚未明确的问题。

例如用户点名「上下水版扫地机器人」时，不会立即比较型号，而会先核实住房与安装条件、清扫频率、宠物和地面情况，并追问手动换水是否真的是无法接受的痛点；若上下水条件不成立或收益有限，会先把这一判断同步给用户，再确认是否改走水箱版或其他路线。

## 装完的回复长什么样

```
🎯 一句话结论（不超过 20 字）

| 路线 | 产出 | 难度 | 推荐度 |
|---|---|---|---|
| ... | ... | ... | ⭐⭐⭐⭐ |

最推荐先试：...

## 🌿 零工具就能做
1️⃣ 条目名
- 4–6 条写到数值/步骤/材料的 bullet
- 配图 + 一行图注
- 来源链接 ｜ 作者 ｜ 赞数
```

## 安装

```bash
dsh plugin add <本地目录或包名>
```

作为 bundle 安装后，profile 里会多一行 `include:xhs-style`，重启生效。

## 配置

当前版本无配置项，装即生效。以下参数后续会外置为 Config：

- 图片落盘目录（默认使用当前工作区的 `xhs-assets/<日期>/`）
- 禁用词清单（可在默认清单上增删）
- 排版严格度（严格 / 宽松）

## 规则清单

| 模块 | 内容 |
|---|---|
| 需求澄清 | 选品与竞品任务前置触发；2–3 轮反问；需求确认后才调研与出稿 |
| 方案重估 | 比较原方案、替代方案、最低成本方案；允许低配或不购买 |
| 排版骨架 | 钩子、星级表、门槛分组、编号条目、短行留白 |
| 内容密度 | 每条目 4–6 条实操 bullet，写到数值与材料级 |
| 图文并茂 | 落盘、内嵌、图注、一图一链、来源作者核对 |
| 内容审核 | 只取正文媒体区；逐张读图核验；不合格回源重找并备备胎 |
| 用词红线 | 禁用称呼类、感叹类、营销话术三类烂词 |
| 例外 | 代码/命令/路径原样；正式文档不适用；用户可即时关闭 |

## 隐私

插件本身无网络请求、无遥测、无文件写入。图文能力取决于 agent 侧可用的浏览与读图工具；图片是否落盘、落盘到哪，由使用方决定。
